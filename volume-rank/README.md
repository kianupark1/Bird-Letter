# 어디에 몰렸나 (가칭) — 앱인토스 미니앱 시안

기간별(1일·1주·1달·3달·6달·1년) 거래대금/거래량 순위 + "요즘 몰린 분야" 한 줄 요약. **국내/해외 분리.**
새편지와 완전히 분리된 폴더. 나중에 별도 저장소로 그대로 옮길 수 있음(루트 `package.json` 없음, 새편지 코드 참조 없음).

> ⚠️ 지금은 **샘플 데이터**(가짜 종목·가짜 숫자)다. 실제 시장 데이터가 아니고, 샘플 화면은 홍보 자료로 쓰지 말 것.

## 실행
- `node core/rank.test.mjs` : 순위 계산 시험
- `node build.mjs` : 샘플 데이터 → `app/data.json`
- `app/` 를 아무 정적 서버로 열면 됨 (`index.html`)
- `node screenshot.mjs` : `screenshots/` 에 모바일 캡처 4장
