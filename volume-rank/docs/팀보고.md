# 팀 보고 · 2026-10-08

## 사용자가 할 일 (이것만)
1. 공공데이터포털 로그인 → "금융위원회_주식시세정보" 활용신청 + **이용허락범위(상업적 이용 가능 여부)** 확인
2. 해외주식 데이터 출처 결정(아래 데이터팀 참고)
3. 시안 디자인 검수 (`screenshots/` 4장)
4. 앱인토스 콘솔 등록 → 번들 업로드·검수 신청
5. 출시 직전 법 전문가 확인 1회 (면책 문구)

## 기획·디자인
- 구조: 국내/해외 탭 → 기간 6개 → 기준(거래대금/거래량) → "요즘 몰린 분야" 요약 → 순위(10개씩 더 보기) → "처음이세요?" 설명 → 고지.
- 초보자용 장치: 종목 옆 분야 태그, 맨 위 한 줄 요약("가장 많이 몰린 분야는 ○○이에요"), 분야 비중 막대, 변화는 "▲ 늘었어요 / ▼ 줄었어요" 글자 포함.
- 색: 증가=청록, 감소=회색. **빨강/파랑을 쓰지 않음**(국내 시세의 상승/하락 색과 헷갈려 "가격이 올랐다"로 오해할 수 있음).
- 터치 영역 44px, 대비는 본문 4.5 이상 기준으로 색을 골랐음(정식 대비 계산은 QA 단계에서 다시).
- 라이트 모드(앱인토스 요건). 접속 직후 바텀시트 없음(요건) — 고지는 화면 아래 상시 표시.
- 이름 "어디에 몰렸나"는 가칭. 앱인토스 앱 이름은 번들 displayName과 글자까지 같아야 하므로 확정 후 한 번만 입력.

## 데이터
- 계산식: 영업일 기준 최근 N일 합계(1·5·21·63·126·252) ÷ 그 직전 같은 길이 합계 − 1. 비교 구간이 모자라면 계산하지 않음. 거래대금 = 거래량 × 종가(근사. 실제 체결대금 필드가 있으면 그것을 사용).
- 국내: 금융위원회 주식시세 API(하루 지연). **상업적 이용 조건 미확인.**
- 해외: 출처 미정. 후보는 유료 시세 API/데이터 판매처. 해외는 무료·상업 이용 가능 출처가 드물어 **비용·약관 확인이 필요**. 확인 전까지 해외는 샘플.
- 분야(업종/테마) 분류: 출처에 업종 코드가 있으면 사용, 없으면 직접 만든 분류표(상위 100~200개 종목 우선) 필요. 분류 기준을 화면에 밝힐 것.
- 갱신: 장 마감 후 하루 1회 계산해 저장 → 앱은 읽기만(정적 빌드 요건).
- 해외는 시차·휴장일·통화(달러)가 달라 국내와 별도 계산하고, 순위를 섞지 않음.

## 개발
- 계산 모듈 `core/rank.mjs` + 시험 완료(구간 합계, 순위, 변화율, 분야 비중, 이름 중복).
- 시안은 의존성 없는 정적 HTML. 실제 연결 시 앱인토스 SDK 번들(`ait`) 구조로 옮기고 `data.json`은 서버/스토리지에서 읽음. 사용자 식별·로그인은 이 앱에 필요 없음(요건 부담이 작음).

## QA
- 통과: 계산 시험 전부, 4개 화면 캡처 육안 확인(샘플 이름 중복·태그 불일치는 발견해 수정).
- 남은 점검: 대비 수치 계산, 작은 폰(320px) 확인, 앱인토스 전용 점검(`check:toss` 방식 이식), 실제 데이터 검증(원본과 샘플 대조 5종목 이상).

## 법무 초안 (전문가 확인 필요)
- 화면에 항상 표시: "정보 제공용·특정 종목 매수/매도 권유 아님·투자 판단과 책임은 본인·데이터는 전 영업일 기준이며 지연·오류 가능".
- 금지 표현: "추천", "유망", "오를", "사세요", 수익률 보장처럼 읽히는 문구. 요약 문장은 사실만 서술("가장 많이 몰린 분야는").
- 면책 문구가 있어도 무신고 투자자문·권유로 판단될 여지는 표현과 기능에 달려 있음. 정렬 기준이 "거래량"뿐이고 가공 점수나 예측이 없는 지금 구조는 상대적으로 안전하나, **판단은 전문가 몫**.
- 데이터 이용약관 준수(출처 표기, 재배포 제한)와 개인정보(수집 없음)도 확인.

## 마케팅
- 한 줄: "요즘 사람들이 어디에 몰리는지, 한눈에."
- 설명(초안): 기간별 거래 순위를 국내·해외로 나눠 보여줘요. 어떤 분야에 거래가 몰렸는지 한 줄로 알려드려요. 정보 제공용이며 투자 권유가 아니에요.
- 스크린샷: 앱인토스 규격(세로 636×1048 최소 3장)에 맞춰 실제 데이터 연결 후 다시 제작(샘플 화면은 사용 금지).
- 금지: 수익·적중률·"돈 버는" 같은 표현.
