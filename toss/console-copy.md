## 상세 설명 초안

> 새 편지는 실제 거리와 새의 비행 속도만큼 걸려 도착하는 느린 편지예요.
>
> 1. 받는 사람과 노선(서울→부산, 제주, 독도)을 골라요.
> 2. 매, 제비, 비둘기, 까치, 붕붕이, 두루미 중 한 마리를 골라 편지를 맡겨요.
> 3. 새가 지도 위를 날아가는 모습과 도착 예정 시각을 확인해요.
> 4. 도착하면 편지가 열려요. 까치로 보내면 특별한 도착 연출이 나와요.

## 출시 전에 채울 것 (검수 요건)
- [ ] 사용자 식별자 저장과 데이터 유지(서버) — Firebase
- [ ] 신고·차단, 탈퇴 시 데이터 삭제 (채팅 서비스 조건)
- [ ] 토스 로그인 연동, 결제를 쓴다면 토스페이만
- [ ] 정적 빌드(서버 렌더링 금지), 라이트 모드, 토스 내비게이션 바
- [ ] 접속 직후 바텀시트·외부 링크·자사 서비스 유도 없음
- [ ] 빌드 결과물에 `eval`, `new Function` 없음 (자동 검사 예정)
