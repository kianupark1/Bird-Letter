# 아이폰 앱 출시 순서 (애플 결제·승인 뒤)

> 개발팀이 미리 해 둔 것: 맥 없이 GitHub 서버에서 아이폰 앱을 만들어 TestFlight에 올리는 작업(`.github/workflows/ios-release.yml`).
> 대표님은 아래 1~5번을 **한 번만** 하시면 돼요. 그다음부터 앱 올리기는 버튼 한 번이에요.
> 비밀 값(열쇠 파일·번호)은 **채팅에 붙이지 말고** GitHub 비밀 값 칸에만 넣어 주세요.

## 1. 앱 번호(번들 ID) 등록 (약 3분)
1. https://developer.apple.com/account/resources/identifiers/list 열기
2. 파란 **[+]** → **App IDs** → 계속 → **App** → 계속
3. Description: `Saepyeonji` / Bundle ID: **Explicit** → `com.saepyeonji.app`
4. 아래 기능 목록에서 **Sign In with Apple**, **Push Notifications** 체크
5. **Continue** → **Register**

## 2. App Store Connect에 앱 만들기 (약 3분)
1. https://appstoreconnect.apple.com/apps 열기
2. 왼쪽 위 **[+]** → **신규 앱**
3. 플랫폼 **iOS** / 이름 `새편지` / 기본 언어 **한국어** / 번들 ID **com.saepyeonji.app** / SKU `saepyeonji-ios` / 사용자 액세스 **전체 액세스**
4. **생성**
- 이름 `새편지`가 이미 쓰이고 있다고 나오면 화면 사진을 보내 주세요(다른 이름 후보를 드릴게요).

## 3. 자동 올리기 열쇠 만들기 (약 5분)
1. 팀 번호: https://developer.apple.com/account → 아래 **멤버십 세부 사항**의 **팀 ID**(10글자)를 확인
2. 열쇠: https://appstoreconnect.apple.com/access/integrations/api → (처음이면 **액세스 요청** → 동의) → **[+] 또는 API 키 생성**
3. 이름 `github` / 액세스 **관리자(Admin)** → **생성**
4. 줄 오른쪽 **API 키 다운로드** → `AuthKey_XXXXXXXXXX.p8` 파일이 받아져요(**딱 한 번만** 받을 수 있어요, 잘 보관)
5. 같은 화면의 **키 ID**(10글자)와 위쪽 **Issuer ID**(긴 번호)를 확인
6. GitHub 비밀 값에 넣기: https://github.com/kianupark1/Bird-Letter/settings/secrets/actions → **New repository secret** 4번

| Name | Secret에 넣을 것 |
|---|---|
| `APPLE_TEAM_ID` | 1번의 팀 ID |
| `ASC_KEY_ID` | 키 ID |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_KEY_P8` | .p8 파일을 메모장(텍스트 편집기)으로 열어 **전체 복사**(`-----BEGIN PRIVATE KEY-----`부터 끝까지) |

## 4. 앱 알림·애플 로그인 열쇠 만들어 Firebase에 올리기 (약 7분)
1. https://developer.apple.com/account/resources/authkeys/list → **[+]**
2. 이름 `saepyeonji key` / **Apple Push Notifications service (APNs)** 체크 → **Configure** → 환경 **Sandbox & Production** → 저장
   - 같은 화면에서 **Sign in with Apple**도 체크 → **Configure** → Primary App ID **com.saepyeonji.app** → 저장 (계정 삭제 때 애플 로그인을 철회하는 데 필요, 애플 5.1.1(v))
   - **Continue** → **Register**
3. **Download** → `.p8` 파일(이것도 한 번만), 화면의 **Key ID** 확인
4. https://console.firebase.google.com/project/bird-letter/settings/cloudmessaging → 아래 **Apple 앱 구성** → 새 편지 아이폰 → **APNs 인증 키 [업로드]** → 파일·키 ID·팀 ID 넣기 → 업로드
5. https://console.firebase.google.com/project/bird-letter/authentication/providers → **Apple** → 사용 설정 → 아래 **OAuth 코드 흐름 구성**에 **Apple 팀 ID**·**키 ID**·**비공개 키**(같은 .p8 파일을 메모장으로 열어 전체 복사) → 저장 (서비스 ID 칸은 비워도 됨 「미확인」)

## 5. 내 아이폰에 TestFlight 받기 (약 2분)
1. 아이폰 앱스토어에서 **TestFlight** 받기(애플 공식, 무료)
2. https://appstoreconnect.apple.com/apps → 새편지 → **TestFlight** → 내부 테스트 → **[+]** 그룹 만들기 → 대표님 Apple ID 추가

## 6. 앱 올리기 (그다음부터 매번, 버튼 한 번)
- 개발팀이 GitHub Actions의 **"아이폰 앱 올리기(TestFlight)"**를 실행해요(대표님 몫 아님).
- 20~40분 뒤 아이폰 TestFlight 앱에 **새편지**가 뜨면 **설치** → 시험.

## 막히면
- "No profiles for 'com.saepyeonji.app'" 같은 오류: 1번 등록 확인, 3번 열쇠가 **관리자** 권한인지 확인
- "Cloud signing permission error": 열쇠 권한이 관리자가 아니면 나와요 → 관리자로 다시 만들기
- 애플이 이름·번들 ID를 바꾸라고 하면 화면 사진을 보내 주세요
