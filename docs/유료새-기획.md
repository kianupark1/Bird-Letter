# 유료 새 상품 기획 (첫 버전 범위) · 2026-10-13

> 작성: Product Planner. 디자이너·개발자가 그대로 받아 쓰도록 한 장으로 정리했어요.
> **돈이 오가는 결정이라 재무 → 법무 → 대표 승인 순서예요. 법무 검토 전에는 구현하지 않아요.**

## 1. 결정된 것 (대표님, 2026-10-13)
| 항목 | 결정 |
|---|---|
| 판매 상품 | **붕붕이**, **매** (가장 빠른 새) 두 가지 |
| 구매 전 모습 | **실루엣만**(색·디테일 숨김). 이름·속도·설명·가격은 다 보여줌 |
| 구매 방식 | 새를 누르면 앱스토어 결제로 이동 |
| 가격(첫 안) | 각각 **1,500원**, 둘을 묶으면 **2,500원** |
| 받는 친구 | 보낸 새의 **완전한 모습을 공개**(구매 여부와 상관없이) |
| 매의 사고 확률 | **지금 그대로 100통에 1번**(2026-10-13 확정). 무료 두루미와 같아서 돈을 내도 더 안전해지지 않음. 매가 너무 위험해 보이지 않게만 하는 것이 목적 |
| 접은 것 | 기념일 결제, "죽은 새 대체" 결제 |

## 2. 범위: 첫 버전에서 하는 것
- 새 고르기 화면에서 유료 새는 실루엣 + 잠금 표시 + 가격
- 앱스토어 결제(개별 2개 + 묶음 1개), 구매 복원
- 구매한 새만 보낼 수 있게 서버에서 확인
- 받는 친구는 풀컬러 모습을 봄(편지 화면·도착 화면)

## 3. 사용자 이야기 5개와 완료 조건
**① 잠긴 새를 보고 궁금해진다**
- 새 고르기에서 붕붕이·매가 **검은 실루엣 + 🔒 + "₩1,500 잠금 해제"**로 보인다.
- 이름, 시속, 사고 확률, 설명, 가격은 **가려지지 않고** 보인다.
- 무료 새 4종(까치·제비·두루미·비둘기)은 지금과 똑같다.

**② 눌러서 구매한다**
- "잠금 해제"를 누르면 앱스토어 결제 시트가 열린다(가격이 시트에 표시됨).
- 결제 취소 시 아무 변화가 없다. 성공하면 **즉시 풀컬러**가 되고 바로 고를 수 있다.
- 이미 산 새는 다시 결제 버튼이 보이지 않는다(중복 구매 방지).
- 묶음(2,500원)을 사면 두 새가 모두 열린다. 하나를 이미 가졌어도 이상하게 처리되지 않는다.
- 실패하면 "결제하지 못했어요. 다시 시도해 주세요"처럼 해결 방법이 보인다.

**③ 산 새로 편지를 보낸다**
- 구매한 사람만 그 새로 보낼 수 있다. **서버가 거절**한다(앱을 몰래 고쳐도 안 된다).
- 구매하지 않고 보내려 하면 안내 문구가 나온다.

**④ 받는 친구가 모습을 본다**
- 친구가 붕붕이·매로 보낸 편지는 **풀컬러**로 보인다(편지 화면, 도착 화면, 알림).
- 받은 친구가 새 고르기에 가면 그 새는 **여전히 잠겨 있다**(그래서 사고 싶어진다).

**⑤ 기기를 바꿔도 구매가 남는다**
- **구글·카카오 계정에 연결해야** 구매가 유지된다(익명 계정은 기록이 지워지면 구매도 사라진다).
- 설정에 **"구매 복원"** 버튼이 있고, 눌러서 다시 열린다.
- 계정 연결 전에는 구매 버튼 앞에 "계정을 연결하면 기기를 바꿔도 유지돼요" 안내가 보인다.

## 4. 하지 않을 기능 (이번 버전)
- 뽑기·랜덤 상자(확률형 상품), 사고 면제·구제 상품, 죽은 새 대체 결제
- 구독, 선물하기, 쿠폰·환불 자동 처리
- 웹에서의 결제(웹은 잠금 표시만, 안내는 "앱에서 구매"), 앱 안에서 외부 결제로 안내하는 링크
- 새 색깔 마음대로 바꾸기, 꾸미기 상품 (다음 버전)

## 5. 출시 전에 끝내야 하는 것 (결제를 넣기 때문에)
| 항목 | 담당 | 상태 |
|---|---|---|
| 구글·카카오 로그인 연결 (구매 유지의 전제) | 개발, 대표님(키 발급) | 미시작 |
| 통신판매업 신고, 환불·청약철회 안내 문구 | 대표님, 법무 | 미시작 |

| 서버 구매 검증과 보낼 때 권한 확인 | 개발 | 미시작 |

| 전문가(변호사·세무사) 검토 | 대표님 | 미시작 |

## 6. 법무에 물어볼 것 (문서로 정리됨, 변호사 확인 필요)
1. 매의 사고 확률은 **현재 그대로(100통에 1번)로 확정**했다. 무료 두루미도 같은 값이라 "안전을 돈으로 사는" 구조가 아니다. 이 판단이 맞는지만 확인한다.
   - 앞으로 **매만 더 낮추는 변경은 법무 확인 전에는 하지 않는다.**
2. 실루엣으로 가린 상품의 구매 전 고지(이름·속도·가격 표시로 충분한가), 디지털 상품 청약철회 제한 안내.
3. 만 14세 미만 사용자의 결제와 법정대리인 동의.
4. 통신판매업 신고 필요 여부와 시점(앱스토어 결제도 해당하는지).

## 7. 가격 메모 (재무)
- 앱스토어 한국 최저 가격은 2022년 기준 ₩1,500(현재 가격표 확인 필요, **「미확인」**). 1,500원과 2,500원이 실제 가격 단계에 있는지는 가입 후 확인.
- 소규모 개발자 수수료 15% 가정(2020년 기준, **「미확인」**). 1,500원 상품에서 수수료만 빼면 약 1,275원. 세금은 세무사 확인.
- 묶음 2,500원은 개당 1,250원 꼴이다.

## 6. 추가 결정(2026-10-15, 대표님): 체험권·초대 보상·내 새 꾸미기

> 이 절은 **재무 1차 검토 전의 안**이에요. 돈이 오가는 결정이라 재무 → 법무 → 대표 승인 뒤에 구현해요. 화면 그림은 `docs/시안/images/`(⑥ 새 고르기, ⑨ 친구 초대, ⑮ 가입 선물, ⑯ 체험 끝, ⑰ 내 새 꾸미기).

| 항목 | 내용 |
|---|---|
| 보내기 | **계속 무료**. 횟수 제한 없음 |
| 기본 새 4종 | 비둘기·까치·제비·두루미는 계속 무료 |
| 체험권 | 가입하면 **유료 새(붕붕이·매)를 각각 5회 무료**로 써 봄. 다 쓰면 구매 안내(강요 없이 기본 새로 보낼 수 있음) |
| 초대 보상 | 친구가 **첫 편지를 보내면 둘 다 체험 3회**. 어뷰징 방지: 카카오 계정당 1번, 초대받은 사람이 첫 편지를 보낸 뒤 지급 |
| 내 새 꾸미기 | 새에게 옷·소품(목도리·모자·한복 등), 편지지, 도착 연출을 입힘. **직접 골라서 구매**(랜덤 뽑기 금지), **친구에게도 그 모습으로 보임**, 시즌 한정판(설날 한복 등) |
| 가격 | 예시 ₩1,000~2,000. 확정 전 |

미정(대표님 결정 대기): **매의 속도(90km/h)** 가 "시간 단축 결제"처럼 보일 수 있어서, 유료는 모습·연출 위주로 하고 속도 차이는 기본 새로 나눌지.
확률형(랜덤 뽑기)·사고 면제·시간 단축·분실 구제는 계속 금지.
