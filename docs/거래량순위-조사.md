# 거래량 순위 미니앱 아이디어 조사 (앱인토스 경제 방) · 2026-10-08

## 아이디어
- 기간별(1일·1주·1달·3달·6달·1년) 거래량(·거래대금) 순위
- 거래량이 늘었는지 빠졌는지 변화 표시
- 초보자가 "요즘 이런 분야가 인기구나"를 바로 알 수 있는 화면
- 면책 문구 필수: 투자 권유 아님 / 투자 판단과 책임은 본인 / 데이터 지연·오류 가능

## 확인된 것 (검색 기준, 출처는 대화 참고)
- 공공데이터포털 금융위원회 주식시세정보 API는 실시간이 아님. 장 마감 뒤 익일 새벽에 받아 당일 13시 이후 공개. 주말·공휴일은 다음 영업일에 공개.
- 공공데이터포털/KRX 오픈API는 무료 신청이 가능하고 개발 계정 호출 한도는 약 1만 건. 키 승인에 약 1일.
- 과거(2014) 분쟁조정 사례에서 한국거래소는 시세 데이터를 상업적으로 쓰려면 이용료와 정보이용계약이 필요하다는 입장이었음.

## 확인 못 한 것 (반드시 직접 확인)
1. 주식시세정보 API의 이용허락범위가 앱 서비스(상업적 이용)를 허용하는지. 공공데이터포털 상세 페이지 확인.
2. 한국거래소의 현행 재배포·상업적 이용 조건과 이용료. KRX Data Marketplace 약관 확인 또는 문의.
3. 앱인토스가 금융 정보 서비스를 허용하는지, 심사 기준과 면책 문구 요건. 검색으로 못 찾음. 앱인토스 가이드와 채널톡 확인.
4. 금융 관련 인앱 광고에 별도 제한이 있는지.
5. 법률 검토: 순위·변화 같은 사실 정보만 보여줘도 문구에 따라 투자 권유로 읽힐 수 있음. 전문가 확인 필요.

## 설계 메모
- 순위는 거래량과 거래대금 둘 다 제공 (거래량만 쓰면 저가주가 위로 올라옴).
- 기간 순위는 일별 데이터를 매일 한 번 계산해 저장 (서버 비용 작음). 앱인토스는 정적 빌드라 데이터는 서버/스토리지에서 읽기.
- 업종 표는 아니지만 종목 옆에 한 줄 분류 태그(예: 반도체, 2차전지)를 붙여, 상위권에 어떤 분야가 몰렸는지 한눈에 보이게 하는 방안.
- 데이터 지연(전 영업일 기준)을 화면에 항상 표시.
