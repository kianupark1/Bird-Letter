# 펜팔 법무 점검표 (2026-10-19, 법무팀 정리 · 변호사 검토 전 초안)

대표님 질문: "도시까지만 보이고, 받는 사람이 받겠다·안 받겠다를 정하면 법적으로 문제없지 않아?"

## 1. 그 방식으로 해결되는 것 (지금 앱에 들어가 있음)

| 걱정 | 지금 방식 | 판단 |
|---|---|---|
| 위치 정보 | 상대에게는 **도시까지만**(서울은 구 없이 "서울"), 보내는 사람도 **도시만** 고름. GPS 좌표는 저장 안 함 | 위험 낮음. 다만 "내 위치로 찾기"에서 폰 GPS를 쓰는 부분이 위치정보법 신고 대상인지는 「미확인」 |
| 원치 않는 편지 | 랜덤 편지는 **받기를 직접 켠 사람에게만**(기본 꺼짐), 차단한 사람은 못 보냄, [넘기기]로 다시 안 옴 | 위험 낮음 |
| 개인정보 노출 | 진짜 이름·사진·동네 대신 펜팔 이름, 연락처처럼 보이는 글 자동 가림, 펜팔 편지는 사진 없음 | 위험 낮음(가림은 완벽하지 않음) |
| 신고 | 대화방 🚩 신고·차단, 신고 내용은 서버에 남음 | 있음. **처리 담당자·처리 기준**은 아직 없음 |

## 2. 그 방식만으로는 해결되지 않는 것 (출시 전 꼭 확인)

1. **랜덤채팅 앱 청소년유해매체물 고시(여성가족부)** 「미확인」: 모르는 사람끼리 무작위로 이어 주는 앱은 일정 조건(본인 확인 수단·대화 저장·신고 기능 등)을 갖추지 않으면 청소년유해매체물(19세 이상)로 볼 수 있다고 알려져 있음. 새편지는 편지가 저장되고 신고 기능이 있지만 **본인 확인(실명·휴대폰 인증)이 없음** → 해당 여부와 필요한 조치는 **변호사 확인 필요**. 위치·동의 방식과는 별개 문제.
2. **만 14세 확인**: 지금은 "만 14세 이상이에요" 체크만 있음(자기 신고). 이걸로 충분한지 「미확인」.
3. **스토어 정책**: 구글·애플 모두 낯선 사람과 대화하는 기능에는 신고·차단·운영 정책을 요구함(애플 1.2). 콘텐츠 등급 답변에 "사용자끼리 대화 가능" 표시 필요(`docs/스토어-등록.md`).
4. **신고 처리 운영**: 누가, 며칠 안에, 어떤 기준으로 처리하는지 정해서 `/policy`에 적기.

## 3. 변호사에게 물어볼 질문 (복사해서 쓰기)

- 받기를 직접 켠 사람끼리만, 도시까지만 보이게 무작위로 편지를 이어 주는 기능이 랜덤채팅 청소년유해매체물 고시 대상인가요? 대상이면 본인인증만 추가하면 되나요?
- 만 14세 이상 자기 신고 체크로 충분한가요?
- 폰 GPS로 동네(구)를 찾아 주고 좌표는 저장하지 않는 경우 위치정보사업 신고가 필요한가요?
