## A. 유튜브 채널 이름 잡기
1. 사파리에서 https://www.youtube.com/channel_switcher 열기 → 구글 로그인
2. 화면이 깨지면 주소창 왼쪽 "가가" → "데스크탑 웹사이트 요청"
3. **+ 채널 만들기** → 이름 `새 편지`, 핸들 `saepyeonji`
4. 프로필 사진: `promo/sns/profile-dahong.png`(다홍 까치)

## B. 인스타 프로페셔널 계정 전환 (무료, 광고·자동 게시에 필요)
1. 인스타 앱 → 오른쪽 아래 내 프로필 → 오른쪽 위 **☰**
2. **계정 유형 및 도구** → **프로페셔널 계정으로 전환**
3. 카테고리: `앱 페이지`(없으면 `소프트웨어`) → 유형: **비즈니스**
4. 연락처 공개는 이메일만: `animalmode@naver.com` (전화번호·주소는 넣지 않기)

## C. 카카오톡 채널 (고객센터 겸)
1. https://business.kakao.com 열기 → 카카오 계정으로 로그인
2. **카카오톡 채널** → **새 채널 만들기**
3. 붙여 넣을 값:
   - 채널 이름: `새 편지`
   - 검색용 아이디: `saepyeonji` (이미 있으면 `saepyeonji_app`)
   - 소개 글: `새가 실제 거리만큼 날아서 전해 주는 느린 편지 🕊 궁금한 점은 여기로 편하게 물어봐 주세요.`
   - 프로필 사진: `promo/sns/profile-dahong.png`
4. **1:1 채팅 켜기**(고객 문의 받는 곳). 자동 답변 문구:
   `안녕하세요, 새 편지예요 🕊 남겨 주신 내용은 확인하는 대로 답해 드릴게요. 편지가 안 보이거나 오류가 있으면 화면 사진을 같이 보내 주세요.`

## D. 네이버 블로그
1. https://section.blog.naver.com 열기 → 네이버 로그인(animalmode 계정)
2. 블로그 설정 → 블로그 이름 `새 편지 이야기`, 별명 `새 편지`
3. 소개 글: `기다림이 즐거운 편지, 새 편지. 만드는 이야기와 새 소식을 올려요.`
4. 첫 글은 출시 날 홍보팀이 써 드려요(지금은 만들기만).

## E. 페이스북 페이지 + 메타 비즈니스 (유료 광고와 인스타 자동 게시에 필요)
1. https://www.facebook.com/pages/create 열기 → 페이지 이름 `새 편지`, 카테고리 `앱 페이지`
2. 소개: `새가 실제 거리만큼 날아서 전해 주는 느린 편지, 새 편지`
3. https://business.facebook.com 열기 → **비즈니스 포트폴리오 만들기** → 이름 `BRUNOSONO`, 이메일 `animalmode@naver.com`
4. 설정 → **계정 → 페이지** 에서 방금 만든 페이지 추가, **Instagram 계정** 에서 `saepyeonji` 연결
5. 결제 수단(카드)은 **광고를 시작할 때** 넣어요(지금은 넣지 않아도 돼요).
