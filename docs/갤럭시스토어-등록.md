# 갤럭시 스토어 출시 (2026-11-11, 대표님: "갤럭시 스토어 먼저, 플레이 나오기 전엔 갤럭시 스토어로 홍보하면서 플레이는 곧 출시")

플레이(개인 계정 테스터 12명×14일)가 나오기 전까지 삼성 폰 사용자를 받는 다리. 테스트 기간 규칙 없음, 심사 며칠 「미확인」.

## 대표님 순서
1. https://seller.samsungapps.com 가입(삼성 계정, 개인/개인사업자, 판매자 이름 부르노소노·BRUNOSONO, animalmode@naver.com)
2. [앱 등록] → Android → 기본 언어 한국어 → 무료
3. 바이너리: GitHub Actions "안드로이드 출시 파일 만들기" 최신 실행의 Artifacts → `app-release.apk`
4. 앱 정보: 이름 `새편지`, 짧은·자세한 설명은 `docs/스토어-등록.md` 2·3번 그대로(슬로건 포함), 카테고리 소셜(또는 커뮤니케이션), 개인정보처리방침 https://bird-letter.vercel.app/privacy , 고객 이메일 animalmode@naver.com
5. 그림: 아이콘 512×512(`assets/` 앱 아이콘), 화면 사진 `promo/store/phone-1~5.png`, 대표 그림 `promo/store/feature-1024x500.png`
6. 연령 등급: 펜팔·채팅 있음 → 만 15세(또는 스토어 기준 가장 가까운 등급), 신고·차단 있음
7. 국가: 대한민국만 → 심사 제출

## 개발팀이 켤 것(갤럭시 스토어에 나온 날)
- `src/lib/release.ts STORE.galaxy = true` → 삼성 폰의 초대·편지·첫 화면에 "갤럭시 스토어에서 앱 받기"(플레이가 나오면 자동으로 플레이 우선)
- `promo/schedule.json stores.galaxy = "https://galaxystore.samsung.com/detail/com.saepyeonji.app"` → 모든 글에 "👉 갤럭시 스토어 바로 가기 · 구글 플레이는 곧 출시돼요"
- `npx tsx promo/build-soon.mts` 다시 → 첫 장 띠 "갤럭시 스토어에서 ‘새 편지’ · 구글 플레이는 곧 출시돼요"

## 주의
- 갤럭시 스토어 APK는 우리 업로드 열쇠로 서명됨 → 구글 로그인이 되려면 Firebase 안드로이드 앱에 업로드 열쇠 SHA-1(`FB:1D:40:…:12:A7`)이 등록돼 있어야 함 「미확인」(카카오 키 해시는 등록 완료).
- 앱 안 결제(우표)는 갤럭시 스토어에선 삼성 결제가 따로 필요 → 출시 때는 무료라 나중에.
