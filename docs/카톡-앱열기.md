# 카카오톡에서 링크를 누르면 앱으로 바로 열리게 하기 · 2026-10-13

> 요구: **카카오톡에서 링크를 누르면 앱이 있을 때 앱에서 바로 열릴 것. 한계 없이 시도.**
> 이 문서는 확인된 한계와, 그 한계를 넘기 위한 **3겹 방법**을 정리해요. 실제 시험은 애플·구글 가입 뒤에 가능해요.

## 1. 확인된 한계
- 카카오톡 안에서 **유니버설 링크(iOS)·앱 링크(안드로이드)**를 누르면 앱이 바로 열리지 않고 **카카오톡 자체 브라우저**로 열리는 사례가 개발자 커뮤니티에 계속 보고돼요 [(카카오 데브톡)](https://devtalk.kakao.com/t/ios-android/134879) [(Branch 사례)](https://devtalk.kakao.com/t/branch/151358).
- 카카오 쪽 답변은 "인앱 브라우저는 카카오톡 기능이라 고객센터로 문의"로, **링크를 그냥 붙여넣는 방식은 100% 보장하기 어려워요.**
- `kakaotalk://web/openExternal?url=...`은 **다른 브라우저로 넘기는 용도**로 쓰이는 것으로 보이지만, 앱 실행에 공식 지원되는지는 확인하지 못했어요(**「미확인」**) [(데브톡)](https://devtalk.kakao.com/t/topic/150815).

## 2. 한계를 넘는 3겹 방법
| 겹 | 방법 | 효과 |
|---|---|---|
| **① 카카오링크로 보내기 (가장 강력)** | 앱 안에서 **"카카오톡으로 보내기"** 버튼을 만들어요. 카카오링크는 메시지 버튼에 **앱 실행 정보(iosExecutionParams, androidExecutionParams)**를 담을 수 있어서, 앱이 있으면 **앱이 바로** 열려요. 우선순위는 앱 실행 정보 > 모바일 웹 > 웹이에요 [(카카오 SDK 문서)](https://developers.kakao.com/sdk/reference/flutter/release/kakao_flutter_sdk_template/Link/iosExecutionParams.html) | 카톡 브라우저를 거치지 않아요 |
| **② 링크 붙여넣기 대비** | 링크를 눌러 웹으로 열렸을 때 화면 위에 **[앱에서 열기]** 버튼(앱 주소 `saepyeonji://`)을 크게 보여요. 카카오톡 인앱 브라우저면 **"우측 메뉴에서 다른 브라우저로 열기" 안내**를 보여요 | 한 번 더 눌러서 앱으로 가요 |
| **③ 일반 브라우저·다른 메신저** | iOS 유니버설 링크, 안드로이드 앱 링크를 설정해서 **사파리·크롬·라인·문자에서는 앱이 바로 열려요** | 대부분의 경우 자연스럽게 열려요 |

앱이 없는 사람은 웹에서 편지를 볼 수 있고 **[앱 설치] 안내**가 보여요.

## 3. 준비물 (가입 뒤에 가능한 것)
| 항목 | 내용 | 담당 | 시점 |
|---|---|---|---|
| 번들 ID·패키지명 확정 | `com.saepyeonji.app`(등록 뒤 변경 불가) | 대표님 | 가입 전 |
| 도메인 연결 파일 | `/.well-known/apple-app-site-association`, `/.well-known/assetlinks.json`을 사이트에 올려요 | 제가 | 가입·서명 후 |
| 카카오 앱 설정 | 도메인, iOS 번들 ID, 안드로이드 패키지명·키 해시 등록 | 대표님(안내는 제가) | 가입 후 |
| 카카오링크 SDK 연결 | 앱(Capacitor)에 카카오 SDK 플러그인 연결, 공유 버튼 | 제가 | 가입 후(플러그인 선택은 「미확인」) |
| 링크 미리보기 카드 | 링크를 붙였을 때 보이는 제목·그림(이미 홍보 이미지 있음) | 제가 | 지금 가능 |
| 실제 기기 시험 | 아이폰·갤럭시에서 카톡 → 앱 열림 확인 | 대표님과 함께 | 가입 후 |

## 4. 솔직한 한계
- **링크를 그냥 붙여넣었을 때 카카오톡에서 앱이 바로 안 열리는 것은 카카오톡의 동작이라 우리가 완전히 막을 수 없어요.** 그래서 **①번(카카오링크로 보내기)을 대표 공유 방법**으로 하고, ②·③으로 보완해요.
- 정확한 동작은 **iOS와 안드로이드, 카카오톡 버전마다 달라서** 실제 기기에서 시험해야 확정돼요.
