# 앱을 닫아도 오는 알림(푸시) 켜는 법

코드는 모두 들어 있어요. 아래 **준비물 3가지**를 Vercel에 넣고 다시 배포하면 켜져요. (넣기 전에는 설정 화면에 "준비 중이에요"로 보이고, 앱이 열려 있는 동안의 팝업은 그대로 동작해요.)

## 동작 방식 (그림 없이 한 줄)
편지를 보내면 → 폰이 "도착 시각에 알려줘"를 서버에 맡기고 → 예약 서비스(Upstash QStash)가 시각까지 들고 있다가 → 서버가 구글·애플·모질라 알림 서버로 보내고 → 폰에 알림이 떠요.
Firebase 유료 요금제(Blaze)는 필요 없어요.

## 준비물 ① 예약 서비스 (Upstash, 무료로 시작)
1. https://console.upstash.com 에서 가입(구글 또는 GitHub 로그인).
2. 왼쪽 메뉴에서 **QStash**를 눌러요.
3. 화면에 나오는 값 3개를 복사해 둬요: `QSTASH_TOKEN`, `QSTASH_CURRENT_SIGNING_KEY`, `QSTASH_NEXT_SIGNING_KEY`.
   - 이 값들은 비밀이에요. 채팅이나 깃에 올리지 마세요.
4. 무료 한도(하루에 보낼 수 있는 예약 수)는 Upstash 요금표에서 확인하세요. 편지 한 통에 알림이 보통 2~4개 예약돼요.

## 준비물 ② 푸시 열쇠 한 쌍
컴퓨터의 프로젝트 폴더에서:
```
node scripts/gen-vapid.mjs
```
공개 키와 비밀 키가 나와요. 비밀 키는 남에게 보여주지 마세요.

## 준비물 ③ Vercel에 넣기
Vercel 대시보드 → 프로젝트 → Settings → Environment Variables 에 **Production**으로 6개를 넣어요. (명령으로 넣으려면 `gen-vapid.mjs`가 출력해 주는 줄을 쓰세요. PowerShell에서 `값 | 명령`처럼 파이프로 넣으면 보이지 않는 글자가 붙어서 실패해요. 꼭 `--value`를 쓰세요.)

| 이름 | 값 |
|---|---|
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | 공개 키 |
| `VAPID_PRIVATE_KEY` | 비밀 키 |
| `VAPID_SUBJECT` | `mailto:내이메일@example.com` |
| `QSTASH_TOKEN` | Upstash에서 복사 |
| `QSTASH_CURRENT_SIGNING_KEY` | Upstash에서 복사 |
| `QSTASH_NEXT_SIGNING_KEY` | Upstash에서 복사 |

- `NEXT_PUBLIC_SITE_URL`도 `https://bird-letter.vercel.app`(실제 주소)로 넣어 주세요. 예약 서비스가 이 주소로 "지금 알려줘"를 불러요.
- 넣은 뒤 **다시 배포**해야 반영돼요(`npx vercel deploy --prod --yes`).
- Upstash가 유럽(EU) 지역이면 `QSTASH_URL`도 필요할 수 있어요. 콘솔에 나오는 주소를 그대로 넣으세요.

## 켜졌는지 확인하는 순서
1. 폰에서 사이트를 열고 **설정 → 앱을 닫아도 알림 받기** 스위치가 보이는지 확인(안 보이고 "준비 중"이면 값이 안 들어간 거예요).
2. 스위치를 켜고 "허용"을 눌러요.
3. 주소 끝에 `?test=1`을 붙여 편지를 보내요(예: `/send?test=1`). 약 20초~1분 뒤에 도착해요.
4. 보내자마자 **앱을 닫고** 기다려요. 알림이 오면 성공이에요. 누르면 편지가 열려요.

## 아이폰은 한 단계 더
아이폰은 **홈 화면에 추가한 앱**에서만 알림이 와요. 사파리에서 공유 버튼 → "홈 화면에 추가" → 새로 생긴 아이콘으로 열어서 켜세요. (iOS 16.4 이상)

## 알림이 안 올 때
| 증상 | 확인 |
|---|---|
| 설정에 "준비 중이에요" | Vercel 값 6개가 모두 들어갔는지, 다시 배포했는지 |
| "알림이 막혀 있어요" | 브라우저/폰 설정에서 이 사이트의 알림을 허용 |
| 켰는데 안 옴 | Upstash 콘솔 QStash → Logs에서 예약과 전달 기록을 확인(실패 사유가 나와요) |
| 늦게 옴 | 폰의 절전·방해금지 모드, 아이폰 집중 모드 |

## 알아둘 한계
- 알림은 폰과 운영체제 사정에 따라 늦거나 못 올 수 있어요. 카톡처럼 항상 즉시 간다고 약속할 수는 없어요.
- 이미 예약한 알림은 취소할 수 없어요. 편지를 지워도 도착 시각에 알림은 와요(누르면 "편지를 찾을 수 없어요"가 나와요).
- 앱이 눈앞에 열려 있으면 알림 대신 앱 안의 귀여운 팝업이 떠요(중복 방지).
- 앱인토스 안에서는 이 방식이 동작하지 않아요(토스 쪽 알림 방식은 따로 확인이 필요해요).
