# 구청 방문 질문지 (통신판매업 신고, 2026-10-16 금)

법무·재무 팀 정리. AI가 만든 초안이라 사실 여부는 모두 「미확인」이고, 구청 담당자 답이 우선이에요.
앱 내용: 새편지는 앱 안에서 디지털 상품(유료 새, 붕붕이·매 1,500원 / 묶음 2,500원 안)을 팔 예정. 실물 배송 없음. 아직 돈은 안 받음.

## 가져갈 것 (「미확인」, 전화로 먼저 확인)
- [ ] 사업자등록증 (보유)
- [ ] 신분증
- [ ] 도장 (신청서에 서명으로 대체되는지 확인)
- [ ] 사업자 업종에 전자상거래(통신판매) 관련 업종이 들어 있는지: 세무서에서 업종 추가가 먼저 필요한지 확인

## 물어볼 것
1. 앱 안에서 디지털 상품(유료 새)을 팔 때도 통신판매업 신고 대상인가요?
2. 지금 돈을 받기 전에 미리 신고해도 되나요? 신고 후 영업 시작 시점은 언제인가요?
3. 신고에 필요한 서류와 수수료(등록면허세 등)는 얼마인가요?
4. 구매안전서비스 이용확인증이 필요한가요? 앱스토어 결제만 쓰면 면제되나요?
5. 신고 후 변경 사항(대표 주소·연락처·사이트 주소 변경)은 어떻게 하나요?
6. 사이트(앱) 주소란에 무엇을 적나요? (https://bird-letter.vercel.app, 나중에 도메인을 바꾸면?)
7. 간이과세자는 신고 면제 기준이 있나요?
8. 처리 기간은 얼마나 걸리고, 어떻게 결과를 받나요?
9. 신고 후 정기적으로 해야 하는 일(갱신, 폐업 신고 등)이 있나요?
10. 만 14세 미만 이용자에게 팔 때 따로 필요한 것이 있나요?
