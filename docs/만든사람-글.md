# 만든 사람의 글 — 올릴 곳·붙여 넣을 글 (2026-11-16)

Carrier Pidge는 광고가 아니라 **만든 사람이 직접 쓴 글 한 편**("3주 걸려 이메일보다 느린 메신저를 만들었다")이 개발자 커뮤니티에서 퍼지고, 그걸 기자가 보고 기사를 쓰면서 터졌어요.
새 계정의 X는 팔로워가 없어서 아무도 안 봐요. 그래서 **이미 사람이 모여 있는 곳**에 대표님 이름으로 올려야 해요.
재미 포인트는 "새가 사라짐" 대신 **"새가 노을 구경하느라 늦어요"**(편지는 꼭 도착)예요.

---

## 1. 긱뉴스 Show GN (개발자·기자가 매일 보는 곳)
- 링크: https://news.hada.io/show → 로그인 → [글쓰기]
- 제목: `Show GN: 카톡보다 느린 메신저를 만들었습니다 (서울→부산 참새로 11시간 36분)`
- 주소: `https://bird-letter.vercel.app`
- 본문:
```
혼자 만들고 있는 '새 편지'라는 메신저입니다. 일부러 느리게 만들었어요.

- 보내는 곳과 받는 곳의 실제 거리 ÷ 새의 비행 속도만큼 걸려서 도착합니다.
  서울→부산: 매 3시간 37분 · 비둘기 5시간 · 까치 9시간 17분 · 참새 11시간 36분 (KTX보다 느림)
- 가는 길에 새가 노을을 구경하거나 소나기를 피해 쉬기도 하는데, 편지는 반드시 도착합니다.
- 받는 사람은 도착 전엔 내용을 못 열고, 둘 다 지도 위에서 새가 날아오는 걸 같이 봅니다.
- 받는 사람은 앱이 없어도 링크로 날아오는 모습을 볼 수 있어요.

만든 이유: 답장이 1초 만에 오는 시대라 오히려 설렘이 사라진 것 같아서요.
Next.js + Firebase, iOS는 앱스토어, 안드로이드는 지금 웹으로 쓰실 수 있습니다.
솔직한 피드백 부탁드립니다. 쓸모는… 거의 없습니다 😅
```

## 2. 디스콰이엇 (메이커·스타트업 커뮤니티)
- 링크: https://disquiet.io → 로그인 → [글쓰기] 또는 [제품 등록]
- 위 본문 그대로 + 맨 아래 한 줄: `혹시 써 보시면 첫 편지는 누구한테 보내셨는지 댓글로 알려 주세요 🕊`

## 3. 대표님 개인 스레드·인스타 스토리 (브랜드 계정 말고 본인 계정)
```
혼자 이상한 앱을 하나 만들었어요.
카톡보다 느린 메신저예요. 네, 일부러요 🐤

서울에서 부산까지 참새로 보내면 11시간 36분.
가다가 노을이 예쁘면 구경하고 와요.

이걸로 제일 먼저 누구한테 보내 보고 싶어요?
👉 https://bird-letter.vercel.app
```

## 4. 기자 한 줄 (긱뉴스에 반응이 오면 그 링크와 함께)
- 받는 곳: IT 담당 기자 메일, 블로터·지디넷코리아·아이뉴스24 제보 창
```
제목: 한국판 'Carrier Pidge' — 새가 실제 거리만큼 날아가는 느린 메신저 '새 편지'
본문: 미국에서 화제가 된 느린 메신저(Carrier Pidge·Roost) 흐름의 한국 앱입니다.
서울→부산 참새 11시간 36분, 도착 전엔 못 여는 편지. 1인 개발. 앱스토어 '새 편지'.
```

규칙: 지어낸 후기·가짜 사용자 금지, "실제 새 속도와 같다" 금지("실제 새의 비행 속도를 바탕으로"), 연출한 이야기에는 "연출된 가상의 이야기" 표시.
