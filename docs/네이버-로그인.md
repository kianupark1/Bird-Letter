# 네이버로 가입하기 켜는 법 (대표님 몫, 약 10분)

> 2026-10-28 대표님: "어른들을 위해 네이버로 로그인도 추가해줘".
> 코드는 끝나 있어요(`src/lib/firebase/naver.ts`, `src/app/api/auth/naver/route.ts`, `/auth/naver`).
> 아래 열쇠 2개를 넣으면 첫 화면에 초록색 **[N 네이버로 가입하기]** 버튼이 저절로 나타나요. 넣기 전에는 버튼이 숨어 있어요.
> **비밀 값(Client Secret)은 채팅에 붙이지 말고** Vercel 칸에만 넣어 주세요.

## 1. 네이버 개발자 센터에 앱 등록 (약 5분)
1. https://developers.naver.com/apps/#/register 열기 → 네이버 로그인
2. **애플리케이션 이름**: `새 편지`
3. **사용 API**: `네이버 로그인` 선택
4. **제공 정보 선택**: `별명`(필수), `프로필 사진`(추가). 이름·이메일·전화번호 같은 다른 것은 **고르지 않아요**(필요 없는 정보는 받지 않음)
5. **로그인 오픈 API 서비스 환경**: `PC 웹` 추가
   - 서비스 URL: `https://bird-letter.vercel.app`
   - 네이버 로그인 Callback URL: `https://bird-letter.vercel.app/auth/naver`
6. `모바일 웹`도 추가 → 서비스 URL 같은 주소 `https://bird-letter.vercel.app`
7. **등록하기** → 다음 화면에 **Client ID**와 **Client Secret**이 보여요

## 2. Vercel에 열쇠 2개 넣기 (약 3분)
https://vercel.com/kianupark1-7752s-projects/bird-letter/settings/environment-variables → **Add New** 두 번

| Key | Value | 종류 |
|---|---|---|
| `NEXT_PUBLIC_NAVER_CLIENT_ID` | Client ID | 공개 값(Sensitive 끔) |
| `NAVER_CLIENT_SECRET` | Client Secret | **Sensitive 켬** |

→ 저장한 뒤 **Deployments → 맨 위 배포 ⋯ → Redeploy**(다시 배포해야 버튼이 나와요)

## 3. 시험 (약 2분)
1. 폰에서 https://bird-letter.vercel.app 를 **로그아웃한 상태**로 열기(또는 다른 브라우저)
2. **[N 네이버로 가입하기]** → 네이버 로그인·동의 → 새편지 홈으로 돌아오면 성공

## 막히면
- **"검수 요청"**: 네이버는 앱이 "개발 중"일 때 **등록한 네이버 아이디만** 로그인돼요 「미확인」. 모두가 쓰려면 개발자 센터 → 내 애플리케이션 → 새 편지 → **검수 요청**(서비스 화면 사진·설명 필요, 며칠). 화면 사진은 개발팀이 만들어 드려요.
- 로그인 뒤 "네이버 로그인이 아직 준비 중이에요": 2번 열쇠가 빠졌거나 다시 배포를 안 한 거예요.
- Callback URL이 다르다는 오류: 1-5번 주소 끝이 `/auth/naver`인지 확인.

## 법무 메모
- 받는 정보: 네이버 별명·프로필 사진(앱 이름·얼굴로만 씀, 서버에 따로 저장 안 함) + 네이버 사용자 번호(같은 사람을 알아보는 데만, `naverAccounts`).
- 개인정보처리방침(`/privacy`)의 로그인 항목에 "네이버"를 추가해야 해요(출시 전, 전문가 검토 때 같이).
