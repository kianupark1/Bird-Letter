# 구글 플레이 개인 계정 가입·테스터 12명 (2026-10-26 결정)

> 대표님 결정(2026-10-26): D-U-N-S가 애플 조회 페이지에서 계속 "서비스를 사용할 수 없습니다"라서 **구글 플레이는 개인 계정으로** 가요.
> 개인 계정은 출시 전에 **테스터 12명이 14일 동안 계속 참여**하는 비공개 테스트가 필요해요(구글 규칙 「미확인」: 가입 직전 콘솔 안내로 다시 확인).
> 비밀 값(업로드 키 등)은 채팅에 붙이지 않아요. 신분증 사진을 보낼 때는 번호·주소를 가려요.

## 1. 가입 (대표님, 약 15분 · 25달러 한 번)
1. https://play.google.com/console/signup 열기 → 앱용 구글 계정으로 로그인(가능하면 새편지 전용 구글 계정)
2. 계정 유형: **"본인(개인)"** 선택 (조직 아님)
3. 개발자 이름(스토어에 보이는 이름): `BRUNOSONO` 또는 `부르노소노` — 대표님이 고르기
4. 연락처 이메일 `animalmode@naver.com`, 전화번호 인증
5. 결제: 25달러(한 번만, 해외 결제 카드)
6. 신원 확인: 신분증 사진 올리기 → 보통 며칠 걸림 「미확인」
7. **안드로이드 폰 확인**: 새 개인 계정은 "실제 안드로이드 기기를 쓰는지" 확인을 요구할 수 있어요 「미확인」 → Play Console 앱을 안드로이드 폰에서 한 번 로그인. 아이폰뿐이면 가족·친구 안드로이드 폰을 잠깐 빌려요.

## 2. 앱 만들기 (개발팀이 화면 하나씩 안내)
- 앱 이름 `새편지`, 기본 언어 한국어, 앱(게임 아님), 무료
- 패키지 이름 `com.saepyeonji.app` (첫 앱 파일을 올리는 순간 고정)
- 스토어 글·데이터 보안·콘텐츠 등급 답: `docs/스토어-등록.md`

## 3. 비공개 테스트 (테스터 12명 × 14일)
- 테스터 등록 방법: **구글 그룹 `saepyeonji-testers@googlegroups.com`(2026-10-26 대표님이 만듦, https://groups.google.com/g/saepyeonji-testers)**를 만들어 비공개 테스트에 연결 → 테스터는 그룹에 가입만 하면 됨(이메일을 하나씩 받지 않아도 됨).
- 테스터가 할 일: ①그룹 가입 ②참여 링크에서 "테스터 되기" ③플레이 스토어에서 새편지 설치 ④**14일 동안 지우지 않기**(가끔 열어서 편지 한 통이면 더 좋음)
- 14일이 지나면 콘솔에서 "프로덕션 출시 신청" → 구글 검토(며칠 「미확인」) → 출시.
- 12명이 안 모이면: 대표님 주변 안드로이드 사용자 → 10/26부터 웹 편지를 받은 사람 중 안드로이드 → 앱 개발자끼리 서로 테스트해 주는 커뮤니티 「미확인」(돈을 내는 테스터 대행은 쓰지 않음: 구글 정책 위반 위험).

### 테스터가 자주 물어볼 것 (답)
- **돈 들어?** 아니요, 무료예요.
- **내 정보 가져가?** 새 편지는 이메일·전화번호를 따로 받지 않아요. 테스터 모임은 구글 그룹이 관리해요.
- **아이폰인데?** 아이폰 앱은 앱스토어에 먼저 나와요. 지금은 bird-letter.vercel.app 에서 웹으로 써 볼 수 있어요.
- **뭘 해야 해?** 설치하고 14일만 지우지 않으면 돼요. 편지 한 통 보내 주면 더 좋아요.
- **언제 받아?** 구글이 열어 주면 링크를 다시 보낼게요(며칠 걸려요).
