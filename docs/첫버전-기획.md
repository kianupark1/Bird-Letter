# 새편지 첫 출시 버전 기획 (앱스토어 심사 제출용) · 2026-10-13

> 작성: Product Planner. 디자이너·개발자·검수가 그대로 받아 쓰는 문서예요.
> 원칙: **완전히 준비해서 출시** (속도 때문에 빼지 않아요). 단, 범위를 넓히지 않고 **심사 통과와 첫 사용 경험에 꼭 필요한 것**만 담아요.
> 유료 새(붕붕이·매)는 별도 문서 `docs/유료새-기획.md`를 따라요.

## 1. 한 줄 정의
**친구에게 새로 편지를 보내면, 실제 거리만큼 걸려 도착해요. 보낸 사람과 받는 사람이 같이 기다려요.**

| 편지 쓰기·보내기, 여정 지도, 도착 화면(까치 특별 연출) | 완료 |

## 3. 첫 버전에 더하는 것 (사용자 이야기 5개와 완료 조건)

**① 앱을 닫아도 알림이 온다**
- 편지가 **도착했을 때, 사고(길 잃음·나무 걸림)가 났을 때, 친구가 나에게 편지를 보냈을 때** 푸시가 온다.
- 아이폰·안드로이드 **앱에서** 알림이 온다(웹 푸시와 별도로 앱 전용 푸시).
- 설정의 알림 스위치를 끄면 오지 않는다. 처음 한 번 **알림 허용 안내**가 나온다.
- 실제 폰에서 **알림이 뜨는 것까지** 직접 확인한다(검수).

**② 계정을 연결해서 기록을 지킨다**
- 구글 또는 카카오로 **연결**할 수 있다(가입이 아니라 "연결"이라 몇 번 누르면 끝난다).
- 연결하면 **기기를 바꾸거나 앱을 다시 깔아도** 친구·편지·구매가 남는다.
- 연결 전에는 "연결하면 기록이 안전해요" 안내가 한 번 보이고, 건너뛰어도 쓸 수 있다.
- 연결 해제와 **탈퇴 시 모든 데이터 삭제**가 앱 안에서 된다(애플 규정).

**③ 앱답게 동작한다 (심사용)**
- **인터넷이 없을 때** 오류 화면 대신 "인터넷에 연결되면 다시 시도해요" 안내와 다시 시도 버튼이 나온다.
- 친구 초대 링크를 기기의 **공유 기능**으로 보낼 수 있다.
- 첫 실행 온보딩 3장이 앱에서 정상 동작한다.
- 앱 정보에 **상호·대표·연락처(사업자 정보)**와 개인정보처리방침·약관 링크가 있다.

**④ 유료 새(붕붕이·매)를 살 수 있다**
- `docs/유료새-기획.md`의 사용자 이야기 5개와 완료 조건을 그대로 따른다.
- 전제: ② 계정 연결이 끝나 있어야 하고, 통신판매업 확인·법무·전문가 검토가 끝나야 한다.

**⑤ 안전하게 쓴다 (신고·보호)**
- 받은 편지에서 **신고·차단**이 된다(이미 있음). 신고 처리 담당 연락처가 운영정책에 있다.
- **만 14세 미만** 이용 안내와 결제 제한이 정해져 있다(법무 확정 필요).
- 편지 내용은 **도착 전에는 보낸 사람만** 읽는다(서버 규칙으로 확인).

## 4. 하지 않을 기능 (이번 버전)
- **연락처 연결**(법무 검토 후 다음 버전), 전화번호로 친구 찾기
- **답장 기능**(현재 설정에 "답장" 알림 스위치만 있고 답장 화면은 없어요 → **스위치를 빼거나 이름을 바꿔야 해요**)
- 뽑기·랜덤 상자, 사고 면제·구제 결제, 구독, 선물하기
- 사진·파일 첨부, 편지 예약(날짜 지정) 발송
- 사람이 직접 뛰는 장난 티어, 언어 설정
- 카카오맵 교체(지금 지도 그대로 출시), 위젯
- 웹에서의 결제(웹은 잠금 표시와 "앱에서 구매" 안내만)

## 6. 대표님이 결정할 것 (★)
1. **계정 연결: 구글만 / 카카오만 / 둘 다.** (카카오 키 발급이 더 번거로워요. 한국에서는 둘 다가 자연스러워요)
2. **답장 알림 스위치:** 빼도 되나요? (답장 기능은 이번 버전에 없어요)
3. **푸시 범위:** 위 ①의 3가지(도착·사고·친구 편지)로 충분한가요?
4. **앱 정보에 표시할 사업자 정보**(상호·대표·연락처·주소)를 어디까지 쓸지 (구청 확인 후)

## 7. 위험과 한계
- 심사 반려(웹 껍데기, 4.2): 위 ③이 대응이에요. 반려되면 고쳐서 다시 내야 해요.
- 푸시는 계정 가입 전에는 **실제 시험이 불가능**해요.
- 법적 문서는 **전문가 검토 전에는 정식 문서가 아니에요.**
