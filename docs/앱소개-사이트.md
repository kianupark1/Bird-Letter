# 앱 소개 사이트에 올릴 글 (2026-11-18)

대표님 요청: "광고주나 앱 소개 사이트에 올려 보자, 필히 앱스토어·안드로이드 바로 가기 링크."
이 사이트들은 **대표님 계정으로만 올릴 수 있어서** 글을 미리 써 두었어요. 그대로 붙여 넣으면 돼요.

- 앱스토어 바로 가기: https://apps.apple.com/kr/app/id6828785320
- 안드로이드 바로 가기: https://bird-letter.vercel.app (크롬에서 열고 '앱 설치' 한 번)

---

## 1. 디스콰이엇 (한국 메이커·스타트업 커뮤니티) — 1순위

- 주소: https://disquiet.io → 로그인 → 오른쪽 위 **[+ 프로덕트 등록]**
- 프로덕트 이름: `새편지`
- 한 줄 소개: `카톡 말고, 새가 물어다 주는 편지 — 실제 거리만큼 날아가서 도착하는 메신저`
- 링크: 위 앱스토어 주소 (웹사이트 칸에는 안드로이드 주소)
- 소개 글:

```
카톡은 1초면 가는데, 왜 마음은 더 전하기 어려울까요?

새편지는 편지가 실제 거리만큼 새를 타고 날아가는 메신저예요.
서울→부산, 매는 3시간 37분 · 비둘기 5시간 · 까치 9시간 17분 · 참새 11시간 36분.

✉️ 날아오는 동안 보낸 사람·받는 사람이 지도로 같이 지켜봐요
📜 도착하면 편지가 두루마리처럼 펼쳐져요
📸 사진은 폴라로이드 틀에 담겨 가고, 도착하면 천천히 선명해져요
💌 앱이 없는 사람에게도 링크로 보낼 수 있어요
🌏 모르는 누군가와 펜팔도 (도시까지만, 만 14세 이상)

혼자 만든 앱이에요. 써 보시고 느낀 점 남겨 주시면 꼭 읽을게요.

👉 앱스토어 바로 가기 https://apps.apple.com/kr/app/id6828785320
👉 안드로이드 바로 가기 https://bird-letter.vercel.app

기다림도 소통의 일부입니다.
```

## 2. 긱뉴스 Show GN — 11/23 저녁 8시 (가입 일주일 뒤라 그때부터 글쓰기 가능)

## 3. Product Hunt (해외, 영어)

- 주소: https://www.producthunt.com → 로그인 → **[Submit]** → **[Launch a product]**
- 이름: `Saepyeonji (Bird Letter)`
- Tagline (60자 이내): `A messenger where birds carry your letters, really slowly`
- 링크: 앱스토어 주소
- 설명:

```
Messages arrive as fast as a real bird could fly the distance.
Seoul → Busan: hawk 3h 37m, pigeon 5h, magpie 9h 17m, sparrow 11h 36m.
Watch the bird fly on a map together, then the letter unrolls like a scroll when it lands.
Photos travel as polaroids and slowly develop on arrival.
Korean only for now.

App Store: https://apps.apple.com/kr/app/id6828785320
Android (web app): https://bird-letter.vercel.app
```

- 주의: 앱이 한국어·한국 지도만이라 해외 반응은 「미확인」. 올린다면 한국 시간 오후 4시(미국 서부 0시)에 올리는 게 보통이라고 알려짐 「미확인」.

## 4. Indie Hackers (해외 1인 개발자 커뮤니티, 영어)

- 주소: https://www.indiehackers.com/products → **[Add a product]**
- 3번 Product Hunt 글을 그대로 써요.

## 올리기 전에 볼 것

- 클리앙·뽐뿌·에펨코리아 같은 큰 커뮤니티는 **자기 앱 홍보 글을 막는 게시판이 많아요**. 올리기 전에 그 게시판 공지(규칙)를 꼭 읽어 주세요. 어기면 계정이 정지될 수 있어요.
- "실제 새 속도와 같다"는 말은 쓰지 말 것(대략값이라서). 위 글은 시간만 적었어요.
