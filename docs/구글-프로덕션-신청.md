# 구글 플레이 "프로덕션 액세스 신청" 답안 초안 (2026-11-13, 개발팀)

비공개 테스트 14일이 끝나면 Play Console 대시보드에 **[프로덕션 액세스 신청]** 버튼이 생겨요. 아래 질문 순서와 칸 이름은 구글이 바꿀 수 있어요 「미확인」. 답은 **있었던 일만** 적어요(지어낸 의견·숫자는 쓰지 않음). 화면의 칸에 그대로 붙여 넣으세요.

## 1. 비공개 테스트에 대해

**테스터를 어떻게 모았나요?**
> 앱 개발자들이 서로의 비공개 테스트에 참여하는 테스트 참여 서비스를 통해 테스터를 모았고, 개발자 본인과 가족의 안드로이드 기기로도 내부 테스트를 함께 진행했습니다.

**테스터를 모으기 쉬웠나요?** → "보통" 또는 "어려웠음"(사실대로)

**테스터가 앱을 얼마나 사용했나요?** → 테스트 기간 동안 매일 앱을 열어 실행함(참여 서비스 조건)

**받은 의견 요약**
> 내부 테스트(가족 기기)에서 안드로이드 앱의 구글 로그인이 실패하는 문제를 발견해, Firebase 설정 파일을 고친 빌드 8을 내부 테스트로 배포했습니다. 그 밖에 화면 밝기(기본 밝은 화면), 펜팔 방과 친구 방 분리, 편지 받는 사람 알림 문제를 실제 사용 중 발견해 웹 업데이트로 고쳤습니다.

**의견은 어떻게 모았나요?** → 앱 안 의견 이메일(animalmode@naver.com)·테스트 참여 서비스 채팅·직접 사용

## 2. 앱에 대해

**앱 대상 사용자**
> 친구·연인·가족에게 편지를 보내는 20~40대 한국 사용자와, 천천히 오는 편지의 설렘을 좋아하는 모든 연령. 펜팔 기능은 만 14세 이상.

**앱이 사용자에게 주는 가치**
> 보낸 편지가 실제 거리와 새의 비행 속도를 바탕으로 정해진 시간 동안 지도 위를 날아가 도착하는 '기다림이 있는 메시지' 앱입니다. 보낸 사람과 받는 사람이 같은 지도에서 편지가 어디쯤 날고 있는지 함께 보며 기다리고, 도착하면 두루마리처럼 펼쳐 읽습니다.

**첫 해 예상 설치 수** → 1만 미만 「가정」(사실과 다르면 대표님 판단으로 고르기)

## 3. 출시 준비

**테스트 결과로 바꾼 것**
> 구글 로그인 설정 오류 수정(빌드 8), 알림이 친구가 아닌 받는 사람에게도 가도록 서버 알림 경로 추가, 화면 밝기 설정 추가, 펜팔·친구 대화 분리.

**출시 준비가 됐다고 판단한 이유**
> 같은 앱이 애플 앱스토어에 이미 출시되어 실제 사용자가 쓰고 있고(2026-11-09 출시), 비공개 테스트 동안 앱이 꺼지는 문제 없이 동작했으며, 발견한 문제를 모두 고쳤습니다.

## 신청 전에 확인할 것

- [ ] Play Console → 테스트 → 비공개 테스트 → **테스터 수 12명 이상**이 14일 동안 유지됐는지(대시보드에 "14일 남음" 같은 표시)
- [ ] 정식 출시용 빌드는 **8 이상**(빌드 7은 구글 로그인 안 됨). 승인 뒤 프로덕션 트랙에 빌드 8 또는 새 빌드 9(짹짹 알림 소리)
- [ ] 출시 국가는 **대한민국만**
