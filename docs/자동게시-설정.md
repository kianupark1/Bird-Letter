### X에 올라가는 글
- X는 한글·이모지를 2칸으로 세서 280칸까지예요. 프로그램이 **링크 줄을 빼고**(링크가 있으면 글값이 약 13배 「미확인」) 넘치면 뒤 줄부터 덜어내요. 따로 쓰고 싶으면 글에 `xText`를 넣어요.
- 영상 글은 X에는 영상 대신 **표지 사진**(`promo/video/saepyeonji-15s-cover.png`)으로 올라가요.
- 앱 주소는 X **프로필 링크**에 넣어요(글에 링크를 넣지 않으려고).
- 비용: 쓴 만큼 내요(글 1개 약 0.015달러, 사진 올리기 값은 「미확인」). 하루 1개면 한 달 1달러 안쪽(가정). 미리 충전(크레딧)이 필요해요.

## 내가 해야 할 일 (한 번만)

### 스레드 (쉬운 쪽부터)
1. https://developers.facebook.com 에서 앱 만들기 → 사용 사례에서 **Threads API** 선택
2. 본인 스레드 계정을 테스트 사용자로 추가하고 **액세스 토큰**과 **사용자 ID** 받기
3. 받은 값은 채팅이나 코드에 붙이지 말고 GitHub에만 넣어요 (아래 비밀값 넣기)

### 인스타그램 (조금 더 번거로움)
1. 인스타 계정을 **비즈니스 또는 크리에이터 계정**으로 바꾸기
2. 페이스북 페이지에 연결하기
3. 같은 Meta 개발자 앱에서 **Instagram Graph API** 토큰과 사용자 ID 받기
- 인스타는 **사진이 있는 글만** 올라가요 (`image`가 있는 글)

### 유튜브 쇼츠 (약 20분, 폰으로 가능)
1. https://console.cloud.google.com 열기 → 새 편지 유튜브 채널과 **같은 구글 계정**으로 로그인 → 위쪽 프로젝트 고르기 → **새 프로젝트** → 이름 `saepyeonji-youtube`
2. https://console.cloud.google.com/apis/library/youtube.googleapis.com 열기 → **사용**
3. https://console.cloud.google.com/auth/overview 열기 → **시작하기** → 앱 이름 `새 편지`, 지원 이메일 `animalmode@naver.com`, 대상 **외부** → 만들기
   - **대상(Audience)** 화면에서 **앱 게시(Publish app)** 를 눌러 "프로덕션"으로 바꿔요. "테스트"로 두면 열쇠가 7일 만에 끊겨요.
4. https://console.cloud.google.com/auth/clients 열기 → **클라이언트 만들기** → 유형 **TV 및 입력이 제한된 기기** → 이름 `auto-post` → 만들기
   - 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 GitHub 비밀 값 `YT_CLIENT_ID`·`YT_CLIENT_SECRET`에 넣어요(아래 비밀값 넣기). 채팅에는 붙이지 마세요.
5. GitHub 앱이나 사이트에서 https://github.com/kianupark1/Bird-Letter/actions/workflows/youtube-login.yml 열기 → **Run workflow**
   - 1분쯤 뒤 실행 기록을 열면 "② 코드 입력: XXXX-XXXX"가 보여요.
   - 폰에서 https://www.google.com/device 열기 → 코드 입력 → 유튜브 채널 계정 고르기 → "확인되지 않은 앱" 경고가 나오면 **고급 → 새 편지(으)로 이동** → 허용
   - 몇 초 뒤 작업이 초록 ✓가 되면 `YT_REFRESH_TOKEN`이 저장된 거예요(`GH_SECRETS_TOKEN` 필요).
6. (선택, 완전 자동) 유튜브 API 심사 신청(무료): https://support.google.com/youtube/contact/yt_api_form — 통과하면 Variables에 `YT_PRIVACY` = `public`. 심사 기간 「미확인」.

### 열쇠 자동 연장 (한 번만)
- 인스타는 **페이스북 페이지에 연결된 페이지 열쇠**로 받으면 만료되지 않아요 「미확인」 → 연장이 필요 없어요. 인스타 로그인으로 받았다면 Variables에 `IG_LOGIN` = `instagram`.
- 스레드 열쇠는 약 60일이면 만료돼서 매주 자동으로 연장해요. 연장한 열쇠를 다시 저장하려면 GitHub 토큰이 하나 필요해요:
  https://github.com/settings/personal-access-tokens/new → 저장소 `kianupark1/Bird-Letter`만 → 권한 **Secrets: Read and write** → 만든 값을 비밀 값 `GH_SECRETS_TOKEN`으로 넣기(유효 기간은 최대로).

### 스위치 켜기
GitHub 레포 → Settings → Secrets and variables → Actions → **Variables** 탭 → New repository variable → 이름 `AUTO_POST_ENABLED`, 값 `true`. (기본은 꺼져 있어서 토큰을 넣기 전에는 아무것도 안 올라가요.)

### 비밀값 넣기
GitHub 레포 → Settings → Secrets and variables → Actions → New repository secret

| 이름 | 값 |
|---|---|
| `THREADS_USER_ID` | 스레드 사용자 ID |
| `THREADS_ACCESS_TOKEN` | 스레드 토큰 |
| `IG_USER_ID` | 인스타 사용자 ID |
| `IG_ACCESS_TOKEN` | 인스타 토큰 |
| `X_API_KEY` · `X_API_SECRET` | X 앱 열쇠 2개 |
| `X_ACCESS_TOKEN` · `X_ACCESS_SECRET` | X 계정 열쇠 2개(만료 없음) |
| `YT_CLIENT_ID` · `YT_CLIENT_SECRET` | 유튜브용 구글 클라이언트 2개(위 "유튜브" 4번) |
| `YT_REFRESH_TOKEN` | 직접 넣지 않아요 — "유튜브 로그인" 작업이 넣어 줘요 |
| `GH_SECRETS_TOKEN` | 열쇠 자동 연장·유튜브 로그인 저장용 GitHub 토큰 |

스레드 토큰은 매주 자동으로 연장돼요(`GH_SECRETS_TOKEN`이 있을 때). 그래도 올라가지 않으면 GitHub가 실패 메일을 보내니, 토큰을 새로 받아 다시 넣으면 돼요.

## 글 추가·수정하는 법

`promo/schedule.json`의 `posts`에 한 덩어리를 더하면 돼요.
- `date`: 올릴 날 (한국 시간, 예: `2026-10-14`)
- `to`: `"threads"`·`"instagram"`·`"x"`·`"youtube"`(영상 글만) 중 올릴 곳들
- `image`: `promo/cards` 안의 파일 이름 (없으면 글만)
- `video`: `promo` 아래 영상 경로(예: `video/saepyeonji-15s.mp4`) → 인스타 릴스·스레드 영상, X는 같은 이름의 `-cover.png`
- `xText`: X에만 다르게 올릴 글(없으면 자동으로 줄임)
- `text`: 올릴 글 (줄바꿈은 `\n`)

## 알아둘 점

- 카드 이미지는 레포의 `main` 브랜치에 있어야 인스타가 가져갈 수 있어요. 이 작업이 `main`에 합쳐진 뒤에 켜세요.
- 같은 날 두 번 실행하면 두 번 올라가요 (이미 올렸는지는 기억하지 않아요).
- 숫자(이용자 수 등)는 실제 값이 생기기 전에는 글에 쓰지 마세요.
