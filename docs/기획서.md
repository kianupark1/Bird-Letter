새편지를 **웹**과 **앱인토스** 두 곳에 따로 내고, 30일 안에 **"첫 수익이 실제로 생기는 구조 + 측정 체계"**까지 만든다.

| 키 발급, 사업자·결제(PG) 서류, 통신판매업 신고 | 웹 배포, 자동 점검, 기록 |
| SNS 게시, 최종 결정 | 매일 홍보 초안, 주간 요약 |

## 4. 돈이 생기는 경로 (현실적인 순서)
1. **앱인토스 인앱 광고** — 사업자 등록 없이도 가능하다고 문서에 나옴. 토스 출시와 사용자가 필요.
2. **웹 유료 상품** — 기념일 예약 편지, 명절 한정 새. 통신판매업 신고와 PG 계약 필요.
3. **제휴** — 엽서 인쇄, 지자체·관광 노선 후원. 사용자가 생긴 뒤.

## 5. 두 갈래 홍보
- **웹:** 인스타·스레드(이미지·글 준비됨), 지인 초대 링크 베타, 매일 초안
- **앱인토스:** 이름·스크린샷·설명 최적화, 출시 때 공식 보도자료 가이드 활용. 토스 안 노출은 토스 심사와 정책에 달려 있음
- **공통 문구:** "소식은 날아서 와요". 측정으로 어디가 잘 되는지 비교해 **잘되는 쪽에 집중**

## 6. 위험과 대비
| 위험 | 대비 |
|---|---|
| 토스 반려 | 올리기 전 자동 점검(이름, 외부 코드, 스크린샷, 정적 빌드). 오탐은 채널톡으로 수동 승인 요청 |
| 사용자 부족 | 지인 베타부터, 측정 후 홍보 방향 수정 |
| 결제·세금 | 세무사 확인 |
| 토스 정책·수수료 변경 | 웹도 병행해 한 곳에 의존하지 않기 |
