# 출시 날부터 2주: 인스타·스레드·틱톡·네이버 블로그 (2026-10-22, 대표님: "출시와 함께 바로 홍보")

출시 순서는 **아이폰(앱스토어) 한국 먼저**예요. 안드로이드는 "곧 나와요"로 안내해요.
문구 규칙은 `promo/출시-홍보.md` 1번을 따라요. "실제 새 속도와 같다"는 쓰지 않고, "실제 새의 비행 속도를 바탕으로"라고 써요. 이용자 수 같은 숫자는 실제 값이 생기기 전에는 쓰지 않아요.

## 0. 누가 무엇을 하나

| 채널 | 방식 | 누가 |
|---|---|---|
| 스레드·인스타(+X) | **자동**: 매일 낮 12시, `promo/schedule.json` 일정표 9개 | 개발팀이 출시 날 `launch`(날짜)·`stores.ios`(앱스토어 주소)만 넣음. 열쇠는 출시 1주 전에 대표님과 함께(`docs/자동게시-설정.md`) |
| 틱톡 | **반자동**: 영상·글은 아래에 준비, 올리기만 폰으로(1분) | 대표님 |
| 네이버 블로그 | **직접**: 글 3편 준비, 붙여 넣기(편당 5분) | 대표님 |

## 1. 출시 날 순서 (앱스토어 주소가 나온 날)
1. **대표님**: 아이폰에서 앱스토어 → '새 편지' 받기 → 로그인 → 편지 한 통 보내기(실제로 되는지 확인)
2. **개발팀**: `schedule.json`에 `launch`·`stores.ios`를 넣고 합치기 → 그날 12시부터 스레드·인스타·X 자동 게시
3. **대표님**: 세 SNS 프로필 소개·링크 바꾸기(문구는 `docs/홍보-대표님-할일.md` G)
4. **대표님**: 틱톡 첫 영상 올리기(아래 2번의 1일째)
5. **대표님**: 네이버 블로그 첫 글 올리기(아래 3번의 1편)
6. **대표님**: 아는 사람 30명에게 편지 먼저 보내기(`docs/무료-성장-계획.md` 문구)

## 2. 틱톡: 2주 일정 (영상 3편을 번갈아)

영상은 모두 세로 15초, 소리가 들어 있어요. 앱에서 유행 음원을 작게 덧입혀도 좋아요.

| 날 | 영상 파일 | 첫 줄(문제) |
|---|---|---|
| 1일째(출시 날) | `promo/video/saepyeonji-15s.mp4` | 답장, 너무 빨라서 설레지 않죠? |
| 3일째 | `promo/video/saepyeonji-15s-love.mp4` | 읽씹될까 봐 조마조마할 때 |
| 5일째 | `promo/video/saepyeonji-15s-grandma.mp4` | 전화는 쑥스럽고 문자는 너무 짧을 때 |
| 8일째 | 엄마 편(다른 음원으로 다시) | 같음 |
| 10일째 | 연인 편(다른 음원으로 다시) | 같음 |
| 12일째 | 할머니 편(다른 음원으로 다시) | 같음 |

**올리는 법 (1분)**
1. 영상 파일을 폰에 저장해요. 개발팀이 출시 전에 대표님 폰으로 보내 드려요.
2. 틱톡 앱 → 아래 가운데 **＋** → **업로드** → 영상 고르기 → **다음**
3. 아래 글을 붙여 넣기 → **게시**

**붙여 넣을 글**

엄마 편:
```
엄마한테 편지 보냈는데 도착까지 1일 5시간 🕊
새가 실제 거리만큼 날아서 전해 주는 느린 편지, 새 편지
앱스토어에서 ‘새 편지’ (안드로이드는 곧)
#새편지 #편지 #엄마 #기다림 #감성 #앱추천
```

연인 편:
```
보고 싶은 마음, 4시간 48분 동안 날아가는 중 💌
도착하기 전엔 열어 볼 수 없어서 더 설레요
앱스토어에서 ‘새 편지’ (안드로이드는 곧)
#새편지 #연애 #장거리연애 #편지 #설렘 #앱추천
```

할머니 편:
```
할머니께 까치로 편지 보냈어요 🐦 도착하면 두루마리처럼 펼쳐져요
아침 까치가 울면 반가운 소식이 온다죠
앱스토어에서 ‘새 편지’ (안드로이드는 곧)
#새편지 #할머니 #까치 #편지 #효도 #감성
```

**댓글 답**: 자주 나올 질문의 답은 `promo/출시-홍보.md`의 "댓글 답"에 있어요. 출시 첫 주에는 댓글에 하루 한 번 꼭 답해요.

## 3. 네이버 블로그: 첫 글 3편

네이버에서 찾는 사람이 많은 말(편지 앱·펜팔 앱·느린 편지)을 제목과 첫 문단에 넣었어요. 글마다 사진은 아래 적힌 파일을 쓰고, 태그는 맨 아래 줄을 그대로 넣어요.

**올리는 법 (편당 5분)**
1. 네이버 블로그 앱 → 아래 **✎ 글쓰기**
2. 제목 붙여 넣기 → 본문 붙여 넣기
3. **사진** 버튼 → 적힌 사진 넣기
4. 맨 아래 **태그** 칸에 태그 붙여 넣기 → **등록**

### 1편 (출시 날): 출시 소개
- **제목**: `편지 앱 ‘새 편지’ 출시: 새가 실제 거리만큼 날아서 전해 주는 느린 편지`
- **사진**: `promo/cards/06-launch.png`, `promo/cards/01-concept.png`, `promo/ads/ad-2-map.png`
- **본문**:
```
안녕하세요, 새 편지예요 🕊

요즘 메시지는 보내자마자 도착하죠. 편하지만, 답장을 기다리는 설렘은 많이 사라졌어요.
새 편지는 그 기다림을 다시 즐겁게 만들고 싶어서 만든 편지 앱이에요.

■ 어떻게 쓰나요?
1. 편지를 받을 사람을 고르고
2. 편지를 실어 보낼 새를 고르고 (매·붕붕이·비둘기·제비·두루미·까치)
3. 편지를 써서 날려 보내요

새는 실제 새의 비행 속도를 바탕으로, 보내는 곳에서 받는 곳까지의 거리만큼 시간을 들여 날아가요.
보낸 사람도 받는 사람도 지도에서 새가 지금 어디쯤 날고 있는지 같이 지켜봐요.
편지는 도착한 뒤에만 열어 볼 수 있어요. 도착하면 두루마리처럼 펼쳐지고, 사진은 폴라로이드처럼 천천히 선명해져요.

■ 앱이 없는 사람에게도 보낼 수 있어요
편지를 보내고 링크를 문자나 카카오톡으로 알려 주면, 받는 사람은 앱 없이도 새가 날아오는 모습을 보고 도착하면 열어 볼 수 있어요.

■ 받는 곳
아이폰: 앱스토어에서 ‘새 편지’
안드로이드: 곧 나와요 (그동안 https://bird-letter.vercel.app 에서 먼저 써 볼 수 있어요)

기다리는 시간도 편지의 일부예요. 오늘 한 통, 천천히 보내 보세요.
```
- **태그**: `#새편지 #편지앱 #느린편지 #감성앱 #앱추천 #아이폰앱 #편지`

### 2편 (3~4일째): 새 6종 소개
- **제목**: `편지 앱 ‘새 편지’의 새 6종: 어떤 새로 보낼까요?`
- **사진**: `promo/cards/02-birds.png`, `promo/cards/03-magpie.png`, `promo/cards/05-mishap.png`
- **본문**:
```
새 편지에는 편지를 실어 나르는 새가 여섯 종류 있어요.
새마다 빠르기도, 성격도 달라요. 서울에서 부산(325km)까지 걸리는 시간으로 비교해 볼게요.

· 매: 약 5시간 25분. 가장 빠른 특급 배달
· 붕붕이(드론 새): 약 10시간 50분. 새 편지의 마스코트
· 비둘기: 약 15시간. 가장 기본이 되는 새
· 제비: 약 1일
· 두루미: 약 1일 5시간. 가장 귀한 소식을 전할 때
· 까치: 약 2일 7시간. 느긋하지만, 도착할 때 금빛 테두리와 반짝이가 내려와요 ✨

시간은 실제 새의 비행 속도를 바탕으로 정했어요. 그날 새의 컨디션에 따라 조금씩 달라져요.

■ 새도 가끔 길을 잃어요
나무에 걸리거나 길을 잃으면 조금 늦어져요. 그래도 편지는 사라지지 않고 꼭 도착해요.
새마다 얼마나 자주 그러는지는 새 고르기 화면에 적혀 있어요.

아이폰: 앱스토어에서 ‘새 편지’ / 안드로이드는 곧 나와요
```
- **태그**: `#새편지 #편지앱 #까치 #두루미 #느린편지 #앱추천`

① 멀리 사는 가족에게

도착하기 전에는 열어 볼 수 없어서 더 설레요. 사진을 넣으면 도착했을 때 폴라로이드처럼 천천히 선명해져요.

③ 모르는 누군가와 펜팔
‘펜팔 친구 찾기’로 펜팔 편지를 받겠다고 한 사람에게 새를 날려 보낼 수 있어요.
진짜 이름·사진·동네 대신 펜팔 이름과 도시만 보여요. (만 14세 이상, 신고·차단 기능이 있어요)

기다리는 시간도 편지의 일부예요.
아이폰: 앱스토어에서 ‘새 편지’ / 안드로이드는 곧 나와요
