# 대표님이 아는 사람에게 보낼 문구 (100명 작전 ①, 2026-10-24 홍보팀)

> 순서: 새편지 앱(웹)에서 그 사람에게 **편지를 먼저 보내고** → 보낸 직후 뜨는 "알려 주세요" 창에서 [카카오톡으로 알리기]를 누르면 링크가 담긴 메시지가 자동으로 채워져요. 아래 문구는 그 메시지 **앞에 한 줄 덧붙이거나**, 따로 카톡으로 먼저 보내는 말이에요.
> 규칙(법무): "실제 새 속도와 같다"는 말은 쓰지 않아요. 숫자(사용자 수 등)는 지어내지 않아요.

## 1. 엄마·아빠·가족용
```
엄마, 내가 만든 앱으로 편지 보냈어 🕊
바로 안 가고 새가 진짜로 날아가듯이 천천히 가. 링크 누르면 지금 어디쯤인지 보여!
도착하면 열어 보고, "카카오로 받기" 누르면 답장도 할 수 있어 😊
```

## 2. 친구용
```
야 나 앱 하나 만들었는데 첫 편지 너한테 보냈다 ㅋㅋ
카톡처럼 바로 안 가고 새가 날아가서 몇 시간 뒤에 도착함
링크 눌러서 지금 어디 날고 있는지 구경해 봐 🐦
```

## 3. 연인용
```
방금 너한테 편지 날렸어 💌
바로 못 열어 보고, 새가 도착해야 열려. 기다리는 동안 지도에서 어디쯤 오는지 같이 보자
```

## 4. 단톡방용 (동창·동호회·회사)
```
제가 만든 작은 앱 소개해요 🕊 ‘새 편지’
편지를 보내면 새가 실제 거리만큼 날아가서, 몇 시간·며칠 뒤에 도착해요.
기다리는 동안 지도에서 어디쯤 날고 있는지 볼 수 있어요.
첫 편지 써 보실 분 → https://bird-letter.vercel.app
(써 보고 불편한 점 알려 주시면 바로 고칠게요!)
```

## 5. 카카오톡 프로필 한 줄 (상태 메시지)
```
기다림이 즐거운 편지, 새 편지 🕊 bird-letter.vercel.app
```

## 하루 10명씩 보내는 순서 (대표님 폰, 1명에 약 1분)
1. https://bird-letter.vercel.app → [✉ 편지 쓰기] → 그 사람 이름(예: "엄마") → 짧게 쓰고 ➤
2. "어디 계세요?"가 뜨면 그 사람이 사는 도시 누르기
3. 바로 뜨는 창에서 **[💬 카카오톡으로 알리기]** → 그 사람 고르기 → 위 문구 한 줄 덧붙여 보내기
4. 끝. 받은 사람이 "카카오로 받기"를 누르면 가입 1명 + 친구 1명이에요.

> 팁(효과가 큰 순서 「가정」): 가족 → 오래된 친구 → 연인·배우자 → 단톡방. 한 사람에게는 **새를 다르게** 보내 보세요(매는 빠르고, 까치는 하루). "언제 와?"라는 답이 오면 성공이에요.
