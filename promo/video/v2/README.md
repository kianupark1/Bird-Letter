# 업그레이드 영상 넣는 곳

힉스필드 같은 AI 도구로 다시 만든 영상을 **원래 영상과 똑같은 이름**으로 여기에 넣으면,
그날부터 자동 게시(`scripts/auto-post.mjs`)가 새 영상을 올려요. 이미 올라간 글은 바꾸지 않아요.

- 예: `promo/video/saepyeonji-15s.mp4` → `promo/video/v2/saepyeonji-15s.mp4`
- 표지(`-cover.png`)도 같이 넣으면 X에 새 표지가 올라가요. 없으면 예전 표지를 써요.
- 세로 1080×1920, 15~30초, mp4(H.264·AAC). 인스타 릴스는 90초까지, 유튜브 쇼츠는 3분까지.
