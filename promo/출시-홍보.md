# 새 편지 출시 홍보 준비 (홍보팀 · 2026-10-19 초안)

출시 날 홍보팀이 바로 움직일 수 있게 미리 만들어 둔 자료예요. 예전 자료 `promo/launch-kit.md`는 새 속도가 바뀌기 전 숫자라서 **이 문서를 기준**으로 써요.

**수익 영향**: 홍보 비용은 0원(직접 올리는 글·자동 게시)이에요. 초기 설치 수가 나중에 꾸미기·한정 새 매출의 바탕이 돼요. 설치 수 목표는 데이터가 없어서 「미확인」(출시 첫 주를 재 보고 정해요).

## 1. 홍보 글을 쓸 때 지킬 것 (법무 점검표)

올리기 전에 하나씩 확인해요.

- [ ] "실제 새 속도와 같다"라고 쓰지 않았나요? → "실제 새의 비행 속도를 바탕으로"라고 써요.
- [ ] 이용자 수, 다운로드 수, 별점 같은 숫자를 지어내지 않았나요? (실제 값이 생기기 전에는 안 써요)
- [ ] 다른 회사·앱 이름을 쓰지 않았나요?
- [ ] "가장", "최초", "1위" 같은 말을 쓰지 않았나요? (근거가 없으면 광고법 위반 위험)
- [ ] 펜팔을 소개할 때 "만 14세 이상"을 넣었나요? "새 친구 만나기", "연애"처럼 만남을 앞세우지 않았나요?
- [ ] 아이폰 사용자를 헷갈리게 하지 않았나요? → 아이폰 앱은 "곧 나와요", 지금은 웹으로 써 볼 수 있어요.
- [ ] 협찬을 받고 쓴 글이면 "광고"·"협찬" 표시를 했나요?
- [ ] 화면 사진에 실제 사람 이름·편지 내용이 보이지 않나요? (예시 이름만 써요)

## 3. 출시 일정 (자동 게시)

`promo/schedule.json`에 **출시일 기준**으로 글을 넣어 뒀어요. **출시 전에는 올리지 않아요**(2026-10-19 대표님: 받을 수 있는 곳이 없으면 효과가 적음) → 출시일부터 8개. 계정 가입(인스타·스레드·틱톡)만 미리 해 둬요. 출시일이 정해지면 `"launch": null`을 `"launch": "2026-11-10"`처럼 바꾸기만 하면 돼요(개발팀이 바꿔요). 그러면 매일 낮 12시에 스레드·인스타에 자동으로 올라가요.

| 날 | 글 | 그림 |
|---|---|---|
| **출시일** | 출시 공지 + 구글 플레이 링크 + 아이폰은 웹 | 06 |
| 1일 후 | 제주까지 얼마나 걸릴까 | 04 |
| 2일 후 | 앱 없는 친구에게도 보내기 | 글만 |
| 4일 후 | 까치 도착 연출 | 03 |
| 6일 후 | 길을 잃어도 꼭 도착 | 05 |
| 8일 후 | 펜팔 친구 찾기(만 14세 이상) | 글만 |
| 11일 후 | 랭킹 | 글만 |
| 14일 후 | 답장을 기다려 본 게 언제였나요 | 07 |

- 자동 게시는 **아직 꺼져 있어요**(토큰을 넣고 스위치를 켜야 해요, `docs/자동게시-설정.md`). 꺼져 있으면 이 글을 복사해서 직접 올리면 돼요.
- 출시 전 글(7·5·3·1일 전)은 뺐어요. 새 6종·기다림 카드(02·07)는 출시 뒤 글에서 써요.
- 출시일이 미뤄지면 `launch` 날짜만 바꾸면 모든 글이 같이 밀려요.

## 4. 출시 날 손으로 할 일 (순서대로)

1. 구글 플레이에서 앱이 실제로 열리는지 대표님 폰으로 확인 (설치 → 로그인 → 편지 한 통 보내기)
2. 개발팀에 "출시됐어요" 알리기 → 개발팀이 `launch` 날짜를 넣고 소개 페이지 문구("체험판")를 정식으로 바꿈
3. 가까운 사람 10명에게 카카오톡으로 직접 보내기 (아래 문구)
4. 인스타 프로필 링크를 구글 플레이 주소로 바꾸기
5. 저녁에 댓글·DM 확인하고 아래 5번 답 초안으로 답하기

### 카카오톡으로 직접 보낼 문구 (복사해서 쓰기)

> 나 앱 하나 만들었어! ‘새 편지’라는 건데, 편지를 보내면 새가 실제 거리만큼 날아가서 전해 줘. 서울에서 부산까지 비둘기로 하루쯤 걸려 🕊
> 너한테 첫 편지 보내 볼게. 안드로이드면 여기서 받아 줘 → https://play.google.com/store/apps/details?id=com.saepyeonji.app
> (아이폰이면 앱은 곧 나와. 그동안 내가 보내는 링크로 열어 보면 돼)

- **가장 좋은 홍보는 실제 편지예요.** 대표님이 먼저 편지를 보내면 받는 사람이 링크로 날아오는 모습을 보고, 자연스럽게 앱을 깔아요(앱 안의 [💬 문자로 알려 주기]도 같은 역할).

## 5. 댓글·DM 빠른 답 (홍보 계정용)

길게 물어보거나 환불·개인정보·오류 문의는 **대표님이 직접** 답해요(`docs/고객응대.md`).

| 질문 | 답 |
|---|---|
| 아이폰은 없어요? | 아이폰 앱은 곧 나와요! 그동안 https://bird-letter.vercel.app 에서 먼저 써 보실 수 있어요 🕊 |
| 왜 이렇게 오래 걸려요? | 새가 실제 거리만큼 날아가서 그래요. 빨리 보내고 싶으면 매, 천천히 설레고 싶으면 까치예요! |
| 돈 내야 해요? | 새 6종 모두 무료예요. |
| 편지가 사라지기도 해요? | 길을 잃어 늦어질 수는 있어도, 편지는 꼭 도착해요. |
| 친구가 앱이 없는데요? | 편지를 보낸 뒤 링크를 문자나 카톡으로 알려 주세요. 앱 없이도 열려요. |
| 모르는 사람한테도 보낼 수 있어요? | 네, ‘펜팔 친구 찾기’로요. 펜팔 편지를 받겠다고 한 사람에게만 가고, 진짜 이름 대신 펜팔 이름이 보여요(만 14세 이상). |
| 내 위치가 상대에게 보여요? | 동네 이름(구) 정도만, 직접 알리기로 했을 때만 보여요. 정확한 위치는 저장하지 않아요. |
| 알림이 안 와요 | 앱 설정 → ‘앱을 닫아도 알림 받기’를 켜고, 폰 설정에서 새 편지 알림을 허용해 주세요. |
| 사진도 보낼 수 있어요? | 네, 폴라로이드로 3장까지요. 촬영 위치 같은 숨은 정보는 지워서 보내요. |
| 이상한 편지를 받았어요 | 편지 화면 아래 [신고]와 [차단]을 눌러 주세요. 운영자가 확인해요. |

## 6. 보도자료 초안 (지역 언론·앱 소개 블로그에 보낼 때)

> **"기다림을 되돌려 드립니다" — 새가 실제 거리만큼 날아가는 편지 앱 ‘새 편지’ 출시**
>
> 부르노소노는 [출시일] 편지 앱 ‘새 편지’를 구글 플레이에 출시했다고 밝혔다. 새 편지는 메시지를 보내면 사용자가 고른 새가 보내는 곳에서 받는 곳까지의 거리만큼 시간을 들여 날아가 전해 주는 앱이다. 매·비둘기·제비·두루미·까치, 드론 새 ‘붕붕이’까지 6종의 새는 실제 새의 비행 속도를 바탕으로 걸리는 시간이 다르다. 서울에서 부산까지 매는 약 5시간, 까치는 이틀 넘게 걸린다.
>
> 보내는 사람과 받는 사람은 편지가 지금 어디쯤 날고 있는지 지도로 함께 지켜본다. 내용은 도착하기 전까지 보낸 사람만 읽을 수 있다. 앱이 없는 사람도 링크로 편지가 날아오는 모습을 보고 열어 볼 수 있다.
>
> 대표는 "무엇이든 바로 도착하는 시대에 잊고 있던 기다리는 설렘을 되살리고 싶었다"고 말했다. [대표님 말씀으로 바꿔 주세요]
>
> 아이폰 앱은 [예정 시기]에 나올 예정이다. 문의: animalmode@naver.com

- 언론사 목록과 보내는 시기는 출시일이 정해지면 정해요. 대표님 실명을 넣을지는 대표님이 정해요.
