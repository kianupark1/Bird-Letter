# 새 편지 (bird-letter)

## 이어서 작업하는 법 (어떤 컴퓨터든)

**방법 A. GitHub Codespaces (설치 없음, 추천)**
1. 이 폴더를 GitHub `bird-letter` 레포에 올려요.
2. 레포 페이지 > Code > Codespaces > Create codespace.
3. 터미널에서 `npm install` 후 `npm run dev`.
4. Claude Code를 열고 "새편지 이어서 가자"라고 말하면 `CLAUDE.md`를 읽고 이어가요.

**방법 B. 내 컴퓨터**
1. Node.js LTS와 git을 설치해요.
2. 이 폴더에서 `npm install`, `npm run dev`, 브라우저에서 http://localhost:3000 열기.
3. 이 폴더에서 Claude Code를 실행해요.
